# ESP32-S3 猫咪摄像头 Wi-Fi 预览设计

## 目标

在不保存 TF、不接入音频、也不需要家庭路由器凭据的前提下，让手机连接设备自身热点后，通过浏览器查看 OV5640 的 MJPEG 实时画面。

## 范围与边界

- 设备启用 SoftAP：SSID 为 `CatCam-Setup`，使用 WPA2 密码（编译时配置，不写入源码）。
- HTTP 根路径 `/` 返回一个包含 `<img src="/stream">` 的最小预览页；`/stream` 返回 `multipart/x-mixed-replace` MJPEG。
- 相机仍保持 SVGA、JPEG、单帧缓冲。预览客户端慢或断开时，允许丢预览帧，但每个成功/错误路径都必须归还 frame buffer。
- 第一个版本只服务一个客户端；新客户端收到 503，而不是与现有流争抢相机。
- 不做家庭路由器 STA 配网、TF、AI 上传、音频或连续录像。

## 组件与数据流

`wifi_preview` 负责 SoftAP 生命周期、HTTP 服务及单客户端互斥。HTTP 流处理器每次获取一个 JPEG frame、写入 HTTP 分段响应、立即归还 frame。`main` 在相机稳定性验收后启动该组件；相机初始化失败或 AP/HTTP 启动失败时记录完整错误，不进入流服务。

## 验收

1. 手机可看到并连接 `CatCam-Setup`，浏览器打开 `http://192.168.4.1/` 可加载页面和视频。
2. 连续观看 10 分钟无相机初始化失败、崩溃或 frame-buffer 耗尽。
3. 手机反复连接/断开 20 次后，仍可重新预览；第二客户端收到明确的 503，主流不受影响。
4. 预览运行期间每分钟记录 FPS、失败数、heap、最大连续 8-bit 块和 PSRAM 余量；下一阶段再测试路由器重启与 100 次连接循环。
